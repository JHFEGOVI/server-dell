# ADR-001: SSH Public Key Authentication Only

## Status
Accepted

## Context
The server is exposed to the internet through a WireGuard relay on a DigitalOcean
VPS. Without additional hardening, SSH would be reachable via password authentication,
which is vulnerable to brute-force attacks. Bots continuously scan public IPs for
open SSH ports and attempt credential stuffing.

## Decision
Disable password authentication entirely. Only ED25519 public key pairs are accepted.
Three keys registered: ASUS laptop, Fedora desktop, and Termius mobile client.

## Alternatives Considered
**Keep password authentication enabled:** Simpler to manage new devices, but exposes
the server to brute-force attempts indefinitely. fail2ban mitigates this but does not
eliminate it.

## Consequences
- A 256-bit ED25519 key makes brute-force computationally infeasible
- Any new device requires manual key registration before access is granted
- Losing all registered keys means losing SSH access — offline recovery required
